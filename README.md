# 📊 Algoritmos de Ordenação em C

## 📚 Sobre o projeto

Este projeto foi desenvolvido para estudar e aplicar **algoritmos de ordenação** utilizando a linguagem **C**.

O objetivo é compreender como diferentes métodos de ordenação funcionam na prática, analisando o processo de organização dos dados e comparando a quantidade de **comparações** e **trocas** realizadas durante a execução.

Neste projeto foram implementados os algoritmos:

- 🔹 Insertion Sort
- 🔹 Shell Sort
- 🔹 Merge Sort

Os algoritmos foram aplicados a um conjunto de dados contendo informações de funcionários.

---

## 🎯 Objetivos

- Compreender o funcionamento dos algoritmos de ordenação.
- Implementar os algoritmos utilizando a linguagem C.
- Trabalhar com `struct` e vetores.
- Ordenar dados de acordo com diferentes critérios.
- Contabilizar comparações e trocas realizadas pelos algoritmos.
- Comparar o comportamento do Insertion Sort e do Shell Sort.
- Praticar conceitos de lógica de programação e algoritmos.

---
